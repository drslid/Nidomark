## Status

Nidomark **1.0** runs in Chrome, Edge, Brave, Opera, Vivaldi and Firefox on a computer. It is installed from the [Releases page](https://github.com/drslid/Nidomark/releases) until its store listings are published.

What it does: recreating a whole collection in a new tree, with quick access icons of the most visited sites first and a dozen top-level folders with categories inside, three levels at most; reading pages when titles are not enough; setting dead links, duplicates and adult content apart; a review where everything can be changed (folders at every level, drag and drop, selecting and moving several bookmarks, renaming, removing, undo) with suggestions for every bookmark to check and a new analysis of any folder; partial sorts that add to the folders already there; keeping the previous tree in a dated backup with one-click undo; learning from your corrections; each browser's own folders; emoji folder names, in 21 languages.

## Roadmap

1. **Stores**: Chrome Web Store, Firefox Add-ons, Edge Add-ons and Opera add-ons, to install and update Nidomark like any extension. Brave, Vivaldi and Arc install from the Chrome Web Store.
2. **Sorting on real collections**: corrections from users, more known sites and examples.
3. **Later**: cleaning targeted visits from the browsing history, and a password-protected vault for private bookmarks.
4. **Safari**, when its extensions can read bookmarks.

<Aside>
  Dates are not promised: each step ships when it is tested. Follow the [releases](https://github.com/drslid/Nidomark/releases) to know when one lands.
</Aside>

## Take part

- **Report a misfiled bookmark or a bug** in the [issues](https://github.com/drslid/Nidomark/issues), with the address, where it went and where you expected it, and your browser.
- **Report a vulnerability** privately, as the [security policy](https://github.com/drslid/Nidomark/blob/main/SECURITY.md) describes.
- **Contribute code** following the [contributing guide](https://github.com/drslid/Nidomark/blob/main/CONTRIBUTING.md); [Build from source](/project/development/) gets you started.
