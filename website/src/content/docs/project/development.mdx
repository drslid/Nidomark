## The extension

You need Node.js 22 or later and pnpm; `corepack enable` installs the version pinned in the repository.

```bash
git clone https://github.com/drslid/Nidomark.git
cd Nidomark
corepack enable
pnpm install
pnpm fetch-model   # downloads the pinned model (135 MB) and checks its hashes
pnpm check         # type check and unit tests
pnpm build         # Chrome, Edge, Brave, Opera, Vivaldi: .output/chrome-mv3
pnpm build:firefox # Firefox: .output/firefox-mv3
```

Load `.output/chrome-mv3` from the extensions page with **Developer mode** → **Load unpacked**, or `.output/firefox-mv3` from `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on…**. After a rebuild, reload the extension.

| Command        | Purpose                                                                 |
| -------------- | ----------------------------------------------------------------------- |
| `pnpm dev`, `pnpm dev:firefox` | Development build with hot reload in a new Chrome or Firefox window |
| `pnpm check`   | Type check and unit tests                                               |
| `pnpm e2e`     | End-to-end tests in Chrome, including site reading against a local server and the folders of Opera and Vivaldi; `CHROME_PATH` runs them in Edge, Brave, Opera or Vivaldi |
| `pnpm e2e:firefox` | End-to-end tests in Firefox 142 or later (`FIREFOX_PATH`), including a site that tries to erase its data |
| `pnpm eval`    | Where each bookmark of the test collection goes, and why               |
| `pnpm eval:big` | Coherence on a large messy collection: subjects, places, no folder twice |
| `pnpm zip:all` | The packages published in the releases and the stores, and the sources archive for Firefox's reviewers |

The [development guide](https://github.com/drslid/Nidomark/blob/main/docs/DEVELOPMENT.md) describes the project layout, the sorting pipeline, what differs between browsers and the conventions. The [publishing guide](https://github.com/drslid/Nidomark/blob/main/docs/PUBLISHING.md) covers each store.

## This site

The documentation is an [Astro Starlight](https://starlight.astro.build) site in the `website` folder. It reuses the extension's screenshots, font, icons and categories, so it stays in step with the code.

```bash
cd website
pnpm install
pnpm dev     # http://localhost:4321/Nidomark/
pnpm build   # static site in website/dist
```

Every push to `main` that changes the site is built and published to GitHub Pages by `.github/workflows/pages.yml`.
